# ТЗ: «Пепося и Дудоня: Ночной аукцион»

Офлайн-PWA для iPhone (Safari → «На экран Домой»). Подарок на день рождения. Весь интерфейс на русском,
идентификаторы/имена файлов/код — на английском. Этот документ — источник правды; `CLAUDE_TASK.md` — короткая выжимка.

---------------------------------------------------------------------------------------------------
## 0. Контекст и цель
- Игрок — один человек, играет на своём iPhone, в портретной ориентации, часто короткими сессиями (2–10 минут).
- Герои — два кота: **Пепося** (рыжий кот) и **Дудоня** (серая кошка с розовым бантиком). Они вдвоём держат ночную
  **Лавку** диковин и по ночам ходят в **Забег** за товаром, отбиваясь от насекомых. Главный вредитель — **клобстер**
  (таракано-жук), его босс — **Королевский клобстер**.
- Название сохраняем — «Ночной аукцион», — но **отдельного аукциона в реальном времени нет** (вырезан). «Аукционность»
  живёт в открытии лутбоксов/мешков, редкостях и продаже в Лавке.
- Цель: тёплая, смешная, «залипательная» игра с ощущением открытия лутбоксов, коллекционированием и честной прогрессией.
  Никаких реальных денег, рекламы, сети, аккаунтов.

## 1. Ядро игрового цикла
```
Лавка (хаб) ──[заплатить взнос]──> Забег: карта 8–12 комнат ──> мини-босс «Королевский клобстер» ──> награды ──> Лавка
                    ^                                                     |
                    └──────────── поражение: возврат с частью лута ───────┘
```
1. **Лавка (hub)** — главный экран. Отсюда: начать Забег, Инвентарь/Полки, Альбом наклеек, Журнал комбо, Таланты,
   Магазин улучшений, Ежедневный подарок, Настройки, Авторы.
2. **Забег (run)** — платный: вход стоит монетки (цена растёт с тиром Лавки; первый Забег и Забег при 0 монет — бесплатно,
   чтобы игрок никогда не застрял). При входе генерируется сид и ветвящаяся карта.
3. **Карта** — 8–12 «этажей» снизу вверх, на каждом 2–4 узла, у каждого узла 1–3 связи вверх (как в Slay the Spire).
   Последний узел — всегда мини-босс **Королевский клобстер**. Игрок видит тип каждой комнаты заранее (иконки).
4. **Победа над боссом** → большой мешок лута, монетки, шанс на наклейку. **Поражение** → игрок сохраняет 50% найденных
   монет и все найденные наклейки, предметы из рюкзака забега — по выбору 1 штука (мягкий штраф).
5. Между забегами: продать/выставить находки в Лавке, вклеить наклейки, прокачать таланты/тир.

## 2. Типы комнат
Все типы — data-driven (`data/rooms.json`), веса появления зависят от этажа и тира.

| id | Название | Суть |
|---|---|---|
| `combat` | Бой | пошаговый бой с 1–3 насекомыми (см. §3) |
| `elite` | Гнездо | усиленный бой, лучше награда |
| `loot` | Находка | **лаки-блоки / мешочки**: 1–3 закрытых контейнера, открыть тапом (тряска → вспышка цвета редкости → предмет). Заменяет аукцион |
| `anomaly` | Аномалия | сетка 3×3 (ранние этажи) или 4×4: среди предметов 1–2 «аномальных» (зеркальный, перекрашенный, лишний пиксель, «Глючный»). Найти за ограниченное число тапов. Награда за скорость/точность. Без таймера |
| `shelf` | Полка | сортировка: 6–12 предметов разложить по полкам по правилу (категория / цвет / редкость). Лимит ходов, не времени |
| `wash` | Мойка | помыть предметы: снимает модификатор «Грязный» (и может случайно сделать «Блестящим») |
| `rest` | Лежанка | коты спят: лечение или +временный бафф |
| `event` | Событие | текстовая сценка с 2–3 вариантами (data-driven, ≥30 событий), иногда с проверкой удачи |
| `shop` | Ночной ларёк | купить расходники/предметы за монетки забега |
| `boss` | Королевский клобстер | мини-босс в конце карты, 2 фазы, зовёт клобстеров-миньонов |

Генерация карты: на этажах 1–2 нет элит; `shop` и `rest` не идут подряд; гарантирован минимум 1 `loot` и 1 `rest`
перед боссом на каждом пути (проверить юнит-тестом на 1000 сидах).

## 3. Пошаговый бой
- Сторона игрока: **Пепося** и **Дудоня** (2 юнита, у каждого HP, ATK, DEF, SPD, LUCK, CRIT%). Пепося — «танк/урон»,
  Дудоня — «поддержка/удача». Справа — 1–3 врага.
- Ход игрока: для каждого кота выбрать действие → враги ходят. Очерёдность по SPD.
- Действия кота: **Цап** (атака), **Шипение** (снижает ATK врага), **Мур** (лечение/щит), **Предмет** (расходник из
  рюкзака забега), **Особое** (умение кота, перезарядка N ходов). Набор умений расширяется талантами.
- **Намерения врагов** показываются иконкой над врагом (атака/защита/баф/призыв) — бой тактический, а не рандомный.
- Крит (×1.5–2, звук `crit`), промах (`miss`), статусы: «Липкий», «Отравлен», «Сонный», «Испуган» (data-driven).
- Все случайности — через RNG забега (см. §12). Бой целиком детерминирован по сиду + действиям.
- Враги (готовые спрайты, см. `assets/sprites/enemies/enemies.json`): клобстер (4 вида), жук, гигантский муравей,
  рыжий/серый муравей, оса, муха, паук, скорпион, червь, моль, светлячок, мошка, стрекоза, пчёлка, жучок, крыса,
  летучая мышь, призрак, слизень, мимик. Богомола нет. Статы врагов — в `data/enemies.json`.
- Анимация: idle-кадры, «рывок» атакующего твином (у котов нет кадров атаки — используем run 2–5 + сдвиг), вспышка
  `hurt`, всплывающие цифры урона, тряска экрана на крите (отключаемая в настройках).

## 4. Лут
### 4.1 Предметы
- ≥300 предметов в `data/items.json` (в паке 825 иконок — хватает с запасом). Предмет = иконка + базовое имя + категория
  + редкость + цена + опциональный эффект (расходник/экипировка/коллекционка) + флейвор.
- Категории (под имеющиеся иконки): еда, зелья, оружие-инструменты, одежда, украшения, книги, самоцветы, материалы,
  ключи, контейнеры, хлам, бытовое.
- Имена и флейвор частично генерируются (§10), но у каждого предмета есть стабильный `id`.

### 4.2 Животные
- ≥60 «зверей» (`data/animals.json`, 95 спрайтов готово) — коллекционные «питомцы-наклейки»: выпадают из лаки-блоков,
  дают пассивный бонус, если «приглашены» в Лавку (слоты ограничены).
- Хомяк и собака — перекраски (хомяк из крысы, собака из лисы) — честно.

### 4.3 Редкости
| id | RU | цвет рамки | базовый вес |
|---|---|---|---|
| `common` | Обычный | серый | 60 |
| `uncommon` | Необычный | зелёный | 25 |
| `rare` | Редкий | синий | 10 |
| `epic` | Эпический | фиолетовый | 4 |
| `legendary` | Легендарный | золотой | 0.9 |
| `slop` | Слоп | радужный глитч | 0.1 |
`slop` — самая редкая и самая абсурдная (нелепые предметы с максимально странным флейвором, особая анимация).
Веса — в `data/rarities.json`, модифицируются удачей, талантами и pity.

### 4.4 Модификаторы (префиксы к имени, комбинируются ≤2)
| id | RU | эффект (пример) | визуал |
|---|---|---|---|
| `dirty` | Грязный | цена ×0.5, снимается в Мойке | коричневые пятна-оверлей |
| `shiny` | Блестящий | цена ×2 | блик-анимация |
| `glitchy` | Глючный | случайный бонус/штраф, часть аномалий | смещение каналов/дрожание |
| `cursed` | Проклятый | сильнее, но с минусом | фиолетовая аура |
| `golden` | Золотой | цена ×5 | золотая перекраска |
| `rainbow` | Радужный | цена ×10, +удача | hue-цикл |
Модификаторы рисуются в рантайме (canvas-фильтры/перекраска по палитре), отдельных спрайтов не нужно.

## 5. Альбом наклеек
- ≥20 страниц (`data/album.json`): тематические (Насекомые, Ферма, Саванна, Море, Еда, Зелья, Блестяшки, Слоп…), на
  каждой 6–12 слотов (звери/предметы/враги).
- Наклейки выпадают в забегах и лаки-блоках; дубли превращаются в монетки или «блёстки».
- Полная страница даёт **постоянный бонус** (напр. +5% удачи, +1 слот рюкзака) или **скин** кота (6 готовых скинов +
  перекраски). Анимация вклеивания (`sticker_place`), перелистывание (`page_flip`).

## 6. Комбо
- ≥40 комбо в `data/combos.json`. Триггеры: набор предметов в рюкзаке (напр. «Рыба + Сыр = Пицца-подозрение»),
  последовательность действий в бою (Шипение → Цап = «Внезапный кусь»), зверь + предмет, модификаторы (Грязный +
  Мойка = Блестящий шанс), комнаты подряд.
- Первое срабатывание = «Открыто новое комбо!» + запись в **Журнал комбо**. Неоткрытые показываются как «???» с
  намёком. Счётчик «Открыто N / M».

## 7. Ощущение лутбоксов (без денег)
- Открытие: тряска (`lootbox_shake`) → пауза → вспышка цвета редкости → звук редкости
  (`lootbox_open_common/rare/epic/legendary`) → предмет «выпрыгивает». Чем реже — тем дольше и ярче. Можно пропустить тапом.
- **Pity**: счётчик открытий без epic+; на 10-м гарантирован epic, без legendary 40 открытий → гарантирован legendary.
  Счётчик виден игроку («до гарантированного эпика: 3»). Хранится в сейве.
- **Ежедневный бесплатный лаки-блок**: один раз за календарный день (локальная дата устройства). **Никаких таймеров
  и обратных отсчётов** — просто «Сегодняшний подарок уже открыт. Завтра будет новый».
- **Серия (streak)**: дни подряд с открытием подарка. Бонусы на 3/7/14 день. Пропуск дня не обнуляет, а уменьшает серию
  на 1 (мягко, без наказаний).

## 8. Мета-прогрессия
- **Монетки** — основная валюта (забеги, продажа). **Блёстки** — из дублей наклеек, на таланты.
- **Магазин улучшений** в Лавке: слоты рюкзака, стартовые расходники, слоты зверей.
- **Таланты**: 3 ветки — Пепося (бой), Дудоня (удача/поддержка), Лавка (экономика); по 6–8 узлов (`data/talents.json`).
- **Тиры Лавки** 1–5: открывают новые типы комнат/врагов/предметы, повышают взнос и награды.
- **Экран настроек**: громкость звука, вибрация (если доступна), тряска экрана, скорость анимаций, экспорт/импорт сейва,
  сброс прогресса (двойное подтверждение).
- **Экран авторов**: содержимое `CREDITS.md` (обязательно строка про Kyrise, CC BY 4.0).

## 9. UI и визуал
- Только русский язык интерфейса; все строки — в `data/strings.ru.json` (никаких строк в коде).
- Портрет, один экран без скролла в бою; `env(safe-area-inset-*)` для «чёлки» и home-индикатора.
- Пиксель-арт 16×16 (и родные 32/34), **только целочисленное масштабирование + nearest-neighbor**:
  CSS `image-rendering: pixelated`, canvas `imageSmoothingEnabled=false`, devicePixelRatio учитывать.
- Кнопки ≥44×44 pt. 9-slice рамки из `assets/sprites/ui/nine_slice`. Пиксельный шрифт — свой из CC0 источника или
  системный с fallback; если берётся шрифт — он должен поддерживать кириллицу и лицензия должна быть внесена в CREDITS.
- Шрифт с кириллицей в пак не входит — **это задача кодера** (подобрать CC0/OFL шрифт и положить в репо офлайн).

## 10. Контент — data-driven + генераторы
- Весь контент в `data/*.json` (items, animals, enemies, rooms, events, combos, album, talents, rarities, strings).
  Код не знает конкретных предметов.
- Процедурные генераторы (сидированные): имена предметов (`{модификатор} {база} {суффикс}`: «Грязный носок
  Пророчества»), флейвор-тексты (шаблоны с подстановками), имена врагов-элит («Клобстер-бухгалтер»), реплики котов.
  Словари в `data/gen/*.json`.
- **Горбодак** — только как очень редкий флейвор-текст/упоминание (шанс ~1%), **не босс** и не персонаж.

## 11. Тон
Абсурдный, уютный, добрый. Коты — милые, немного драматичные. Юмор — нелепость предметов и ситуаций.
**Нельзя**: шутки про ссоры пары, бытовые обязанности/«кто моет посуду», упрёки, токсичность, страшилки.

## 12. Технические требования
- **Стек**: ванильный JS, ES-модули (`<script type="module">`), без фреймворков и без сборщика (можно
  необязательный скрипт сборки, но репо должно работать «как есть» со статического хостинга). Canvas 2D для сцены,
  DOM для меню — на выбор кодера, но одно решение на проект.
- **PWA**: `manifest.webmanifest` (name, short_name, `display: standalone`, `orientation: portrait`, theme/background
  color, иконки 192/512), `apple-touch-icon` 180×180, `<meta name="viewport" content="width=device-width,
  initial-scale=1, viewport-fit=cover, user-scalable=no">`, `apple-mobile-web-app-capable`.
- **Service worker** с версионированным кешем (`buro-v<N>`), precache всех ассетов из генерируемого списка
  (`tools/gen_precache.mjs` или ручной список, проверяемый тестом), удаление старых кешей при activate, оффлайн с
  первого же запуска после установки. Никаких сетевых зависимостей в рантайме (шрифты, CDN — запрещены).
- **Аудио**: Web Audio API; `AudioContext` создаётся/резюмится на первом тапе; декодировать `.m4a` (основной),
  `.mp3` fallback; `if (navigator.audioSession) navigator.audioSession.type = 'playback'` (иначе на iOS звук
  глушится переключателем «без звука» — оставить настройку). Индекс звуков — `assets/sfx_index.json`.
- **Сохранения**: `navigator.storage.persist()` при старте; основное хранилище — IndexedDB (или localStorage, если
  сейв < 1 МБ) с зеркалом; **экспорт/импорт сейва как JSON-строки** (копировать в буфер / вставить), с валидацией.
  `save.version` + цепочка миграций `migrations[v] (save) => save`; повреждённый сейв не должен ломать игру
  (бэкап предыдущей версии).
- **RNG**: сидированный (mulberry32/sfc32), отдельный поток на забег; состояние RNG сохраняется. **Состояние
  сохраняется после каждого действия** — закрытие приложения в любой момент не теряет прогресс и не даёт «перероллить».
- **Тесты**: `node --test` (Node ≥18), без зависимостей: RNG детерминизм, генерация карты (инварианты на 1000 сидах),
  боевая формула, pity, daily/streak по датам, миграции сейва, валидация всех `data/*.json` (ссылки на существующие
  файлы спрайтов/звуков, уникальность id, ≥300 предметов, ≥60 животных, ≥40 комбо, ≥20 страниц альбома).
- **Хостинг**: GitHub Pages, **из корня ветки `main`** (решение: корень, не /docs — ассеты и `index.html` лежат в
  корне; все пути относительные `./`, чтобы работало и в подпапке `https://<user>.github.io/<repo>/`).
  Добавить пустой `.nojekyll`. Общий размер репо < 25 МБ (сейчас ассеты ≈ 6 МБ).
- Производительность: 60 fps на iPhone 11+, один `requestAnimationFrame`, никаких утечек при долгой сессии.

## 15. Критерии приёмки
1. Устанавливается на iPhone через «На экран Домой», запускается в standalone, портрет, без белых полос под чёлкой.
2. Работает в авиарежиме после первого запуска (все ассеты в кеше SW), обновление версии подхватывается.
3. Звук играет после первого тапа; громкость/выключение в настройках.
4. Сейв переживает закрытие приложения в любой момент (включая середину боя); экспорт → импорт на чистом устройстве
   восстанавливает прогресс; старая версия сейва мигрирует.
5. Забег полностью проходим, мини-босс побеждаем, поражение не приводит к тупику (всегда есть бесплатный забег).
6. Контент: ≥300 предметов, ≥60 животных, ≥8 видов врагов, ≥40 комбо, ≥20 страниц альбома, ≥30 событий, все 7 типов
   комнат (combat, loot, anomaly, shelf, wash/rest, event, shop) + boss.
7. Ежедневный подарок без таймеров; pity работает и виден; серия считается по локальной дате.
8. Пиксель-арт везде чёткий (nearest-neighbor, целые множители), ни одного размытого спрайта.
9. Весь UI на русском, без опечаток в ключевых экранах; нет шуток про ссоры/быт; Горбодак только во флейворе.
10. `node --test` зелёный; ни одной сетевой зависимости в рантайме; размер репо < 25 МБ.
11. Экран «Авторы» содержит всех авторов из CREDITS.md, включая обязательную атрибуцию Kyrise (CC BY 4.0).
