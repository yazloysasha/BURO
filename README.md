# Пепося и Дудоня: Ночной аукцион

Офлайн-игра для iPhone (PWA): два кота — Пепося и Дудоня — держат ночную Лавку диковин, ходят в Забеги,
дерутся с клобстерами, открывают лаки-блоки и собирают альбом наклеек.

ТЗ — `SPEC.md`, краткое задание — `CLAUDE_TASK.md`, авторы ассетов — `CREDITS.md`.

## Как играть
Лавка — главный экран. **«В Забег!»**: выбираете, кто ведёт (Пепося: +1 к атаке обоим котам, Дудоня: +20% монеток и
находки получше), и идёте по карте снизу вверх к Королевскому клобстеру.
- **Бой**: каждому коту по действию. Над врагами видно, что они задумали и кого бьют. Кнопка со звёздочкой `*` собирает
  комбо. Тап во время анимации пропускает её.
- **Комнаты**: Находка (лаки-блоки), Подсобка (знакомая комната: если что-то в ней не так — повернуть назад), Полка (разложить по правилу), Мойка,
  Событие, Ночной ларёк, Лежанка, Гнездо (сильный враг). Лаки-блок нельзя пропустить: «Дальше» откроется после него.
- **Конец забега**: после победы сами решаете, что продать, а что оставить в коллекцию. После поражения остаётся половина
  монеток и одна вещь, а коты упрямеют: следующий забег легче, пока не победите.
- **Между забегами**: альбом наклеек, таланты (за блёстки), улучшения и тир Лавки (за монетки), звери-гости, скины,
  подарок дня, «Ночная смена» (пять обходов подсобки подряд, награда раз в день). Журнал собирает комбо и найденные аномалии.
  Строка над кнопкой забега подсказывает ближайшую цель. Монеток на взнос нет — забег бесплатный.

Управление на компьютере: мышь; **пробел/Enter** — подтвердить или пропустить анимацию, **цифры** — выбор
(подсказки на кнопках), **Esc** — назад или закрыть окно.

## Установка
### iPhone
1. Открыть адрес игры в **Safari**, дождаться Лавки.
2. «Поделиться» → **«На экран Домой»** → «Добавить».
3. Запускать всегда с иконки: у иконки и у вкладки Safari разные сохранения. После первого запуска с иконки игра работает
   в авиарежиме.

### Windows (Chrome или Edge)
1. Открыть адрес игры, дождаться Лавки.
2. Значок установки справа в адресной строке (или меню → «Установить приложение»/«Приложения»).
3. Игра появится как отдельное окно и запустится без сети.

### Перенос сохранения
Сохранения у каждого устройства свои. Настройки → **Экспорт**: на iPhone «Поделиться…» (в Файлы, AirDrop, себе в сообщения)
или «Копировать», на Windows «Скачать файл». Настройки → **Импорт**: «Выбрать файл» или вставить строку.

### Обновление игры
Когда новая версия выложена, при запуске появится «Готово обновление Лавки!» с кнопкой «Обновить». Если на iPhone
она не появилась, закройте игру и откройте ещё раз. Сохранения при обновлении не теряются.

## Запуск локально
```
python3 -m http.server 8080      # открыть http://localhost:8080
node --test                      # тесты (без браузера, npm install не нужен)
```
Никакой сборки не нужно: ванильный JS (ES-модули), всё работает «как есть» со статического хостинга.
Играть можно на iPhone (вертикально и горизонтально), на планшете и на ПК — раскладка подстраивается сама.

## Деплой на GitHub Pages
1. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
2. Все пути относительные (`./`), поэтому игра работает и в подпапке `https://<user>.github.io/<repo>/`.
   Файл `.nojekyll` уже лежит в корне.

### После изменения файлов
Service worker кеширует всё по списку `precache-manifest.js`. После любой правки ассетов/кода/данных:
```
node tools/gen_precache.mjs      # пересобрать список и поднять версию кеша buro-v<N>
node --test                      # тест упадёт, если список устарел
```

## Плейтест
Нужен только разработчику, в игру не попадает: `npm install && npx playwright install chromium webkit`.
```
node playtest/bot.mjs --out playtest/results/ui.json --careers 3 --runs 4   # бот играет через тапы (--profile desktop)
node playtest/sim.mjs 200 30        # быстрый симулятор баланса на тех же моделях игрока
node playtest/analyze.mjs 200       # все числа для отчёта
node playtest/screens.mjs iphone    # скриншоты всех экранов и аудит вёрстки (iphone|desktop)
node playtest/checks.mjs            # офлайн, старые и битые сейвы, экспорт/импорт, клавиатура
node playtest/hardkill.mjs 5        # SIGKILL браузера сразу после действия
node playtest/contact_backroom.mjs  # подсобка: норма и все аномалии на одном листе
```
Результаты и выводы — в `REPORT_PLAYTEST.md`.

## Контент
- 517 предметов (редкости обычный → слоп), 89 зверей, 23 вида врагов + мини-босс «Королевский клобстер» (2 фазы)
- 10 типов комнат: бой, гнездо, находка (лаки-блоки), подсобка (31 аномалия, `data/anomalies.json`), полка, мойка, лежанка, событие (40), ларёк, босс
- 43 комбо + журнал, 24 страницы альбома, 3 ветки талантов, 5 тиров Лавки, 5 улучшений, 10 скинов
- Модификаторы Грязный / Блестящий / Глючный / Проклятый / Золотой / Радужный рисуются в рантайме
- Pity виден игроку (эпик ≤ 10 блоков, легендарка ≤ 40), ежедневный подарок без таймеров, мягкая серия

## Сейвы
Сохранение после **каждого** действия: localStorage синхронно, IndexedDB сразу следом, плюс ещё раз при
visibilitychange, pagehide и beforeunload; раз в 10 записей — резервная копия. У каждой копии контрольная сумма и счётчик
записей: при загрузке берётся самая новая целая. Состояние RNG — часть сейва, поэтому перезапуск не даёт «перероллить».
Экспорт/импорт — в Настройках (файл, «Поделиться» или JSON-строка). Версии сейва мигрируют автоматически
(`js/core/save.js`, тесты в `tests/save.test.mjs`).

```
python3 tools/prep/build_sprites.py RAW assets
tools/prep/build_sfx.sh             RAW assets/sfx
```
